# کدهای پیوست‌های جدید جزوه «آموزش پایتون از صفر»

این پوشه کدهای **پیشگفتار و پیوست‌های جدید** (پ، ت، ث، ج، چ، ح) را دارد. آن را می‌توانید کنار ریپوی اصلی `python-jozveh` بگذارید یا پوشه‌هایش را در آن ادغام کنید.

| پیوست | پوشه | محتوا |
|---|---|---|
| پ: ماژول‌ها و import | `appendix_pe/` | مثال‌ها، ماژول `mymath`، حل تمرین‌ها |
| ت: اشکال‌زدایی | `appendix_te/` | مثال‌ها، `bugs/` (برنامه‌های معیوب)، `solutions/` (حل) |
| ث: چیدمان در Tkinter | `appendix_se/` | مثال‌های `pack` و `grid` و `place` و `Canvas` و حل تمرین‌ها |
| چ: PEP 8 | `appendix_che/` | قبل و بعد از اصلاح سبک |
| ج: نصب و عیب‌یابی | — | بدون کد قابل اجرا (دستورهای ترمینال در متن کتاب) |
| ح: راهنمای مدرس | `appendix_he/exams/` | سؤال‌های برنامه‌نویسی و خروجی آزمون‌ها و نمونه پاسخ‌ها |

## نکته‌ها

- `bugs/` عمداً اشکال دارند؛ هدف تمرین رفع اشکال است. حل آنها در `solutions/fixNN.py` است.
- در مثال‌های چندفایلی (مثل `appendix_pe/ex07/`) برنامه را از **داخل همان پوشه** اجرا کنید: `python main.py`
- نمونه پاسخ‌های آزمون در `appendix_he/exams/solutions/` است.

## آزمایش

همه فایل‌ها اجرا شده‌اند: مثال‌های متنی با خروجی مقایسه شدند و مثال‌های گرافیکی در محیط مجازی ساخته و دکمه‌هایشان فشرده شد. استثناها: `appendix_te/ex01_console.py` عمداً `ZeroDivisionError` می‌دهد و برنامه‌های `bugs/` معیوب‌اند.
