# اصل کتاب و کدهای جزوه آموزش پایتون از صفر

آموزش پایتون از صفر؛ برنامه‌نویسی متنی و گرافیکی با هم. کدهای کامل جزوه **آموزش پایتون از صفر** (آموزشگاه هوش مصنوعی [Tirotir.ir](https://tirotir.ir)). در هر درس هر مفهوم هم به شکل **متنی (کنسول)** و هم به شکل **گرافیکی (Tkinter)** آموزش داده شده است تا یادگیرنده هم منطق کد و هم ساخت رابط کاربری را هم‌زمان تمرین کند.

## پیش‌نیازها

- **پایتون ۳٫۱۰ یا بالاتر**
- `tkinter` (در ویندوز و مک همراه پایتون نصب است؛ در اوبونتو: `sudo apt install python3-tk`)
- **VS Code** با اکستنشن‌های **Python**، **IZEH** و **Tirotir** (اختیاری اما توصیه‌شده)

> همه مثال‌ها فقط از **کتابخانه استاندارد پایتون** استفاده می‌کنند و به نصب کتابخانه اضافی نیاز ندارند.

## اجرا

```bash
git clone https://github.com/worker2025/python-jozveh.git
cd python-jozveh
python lesson01/ex01_console.py
python lesson01/ex06_gui.py
```

> برخی مثال‌ها به فایل‌هایی نیاز دارند که مثال قبلی می‌سازد (مثلاً `names.txt` در درس ۱۰). مثال‌ها را **به ترتیب** اجرا کنید. برنامه‌هایی که `input` می‌گیرند در ترمینال منتظر ورودی شما می‌مانند.

## کدهای پیوست‌ها

کدهای مربوط به **پیوست‌های کتاب** در همان مخزن، در پوشهٔ زیر قرار دارند:

```
python-jozveh-appendices-code/
```

این پوشه مکمل درس‌های اصلی است و شامل موارد زیر است:

- **کدهای تکمیلی پیوست‌ها** — مثال‌هایی که در متن اصلی درس‌ها نیامده‌اند و به‌عنوان پیوست یا بخش «بیشتر بدانید» به کتاب اضافه شده‌اند.
- **تمرین‌های گسترده‌تر** — نسخه‌های جایگزین یا توسعه‌یافتهٔ برخی تمرین‌های درس‌ها برای تمرین بیشتر.
- **پروژه‌های ترکیبی** — نمونه‌هایی که چند مفهوم از درس‌های مختلف را هم‌زمان به کار می‌گیرند.
- **ابزارهای کمکی** — اسکریپت‌های کوچک برای آماده‌سازی فایل، تولید داده آزمایشی یا بررسی خروجی برنامه‌ها.

ساختار این پوشه نیز بر اساس شماره پیوست یا موضوع مرتب شده است. برای اجرای کدهای آن، همچنان به **پایتون ۳٫۱۰+** و در صورت استفاده از مثال‌های گرافیکی به **`tkinter`** نیاز دارید. اگر در کتاب به پیوستی ارجاع داده شده باشد، کد کامل آن معمولاً در همین پوشه پیدا می‌شود.

```bash
cd python-jozveh/python-jozveh-appendices-code
```

> **نکته:** نیازی به clone جداگانه نیست؛ پوشهٔ `python-jozveh-appendices-code` همراه خود مخزن `python-jozveh` دریافت می‌شود. اگر فقط می‌خواهید درس‌ها را دنبال کنید، همان پوشه‌های `lessonNN/` کافی است؛ اگر می‌خواهید پیوست‌ها و مطالب تکمیلی را هم تمرین کنید، به همین پوشه سر بزنید.

## آزمایش خودکار پنجره‌ها

همه فایل‌ها از نظر نوشتاری بررسی شده‌اند و مثال‌های گرافیکی در یک محیط آزمایشی ساخته و دکمه‌هایشان فشرده شده است. برای تکرار آزمایش روی یک پنجره:

```bash
python tools/smoke_test_gui.py lesson08/ex12_gui.py
```

این ابزار کادرها را پر می‌کند، دکمه‌ها را می‌زند و خطاها را چاپ می‌کند تا از سالم بودن رابط گرافیکی مطمئن شوید.
